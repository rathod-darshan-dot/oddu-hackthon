# Traveloop

Traveloop is a smart AI-powered travel planning web application created for hackathon using HTML, CSS, JavaScript, and Local Storage.

## Features
- AI Trip Planning
- Budget Calculator
- Packing Checklist
- Shared Itinerary
- Notes Management
- Modern UI Design

## Tech Stack
- HTML
- CSS
- JavaScript
- Tailwind CSS

## Developed For
Hackathon Project# oddu-hackthon
